# رصدگر دلار | Dollar Observer (BIG TRADER)

داشبورد معاملاتی فارسی و راست‌به‌چپ (RTL) برای رصد دلار، طلا (XAUUSD)، نقره، یورو و بیت‌کوین — با چارت حرفه‌ای TradingView، تحلیل هوشمند ساختار بازار، پیشنهاد معامله و نسخه‌ی مستقل HTML قابل استفاده در موبایل بدون نیاز به نصب.

## ✨ امکانات

- **چارت TradingView رسمی** — ویجت پیشرفته با ۹ تایم‌فریم (۱ دقیقه تا ماهانه) و نمادهای معتبر
- **تحلیل هوشمند** — تشخیص ساختار بازار (BOS)، نواحی Order Block، نقاط ورود بر اساس فشار خرید/فروش
- **پیشنهاد معامله اسکلپ** — خطوط راهنمای ۴ ساعته (High/Low آخرین کندل بسته‌شده ۴H) + شرایط ورود تایم‌فریم ۱ دقیقه
- **دستیار معامله‌گر** — ماشین‌حساب پیپ‌سایز، حد ضرر / حد سود، مدیریت ریسک
- **نمای بازار** — خلاصه‌ی وضعیت نمادها در یک نگاه
- **اخبار اقتصادی** — تقویم و اخبار مؤثر بر بازار طلا و دلار
- **نسخه‌ی مستقل HTML** — فایل `download/rasadgar-dollar.html` قابل ارسال با ایمیل و اجرا در هر مرورگر موبایل
- **افزونه‌ی وردپرس** — بسته‌ی `download/rasadgar-dollar-wp.zip` برای انتشار روی سایت وردپرسی

## 🛠 تکنولوژی

| بخش | تکنولوژی |
|---|---|
| فریم‌ورک | Next.js 16 + TypeScript |
| استایل | Tailwind CSS 4 + shadcn/ui |
| دیتابیس | Prisma + SQLite |
| چارت | TradingView Advanced Chart (tv.js) |
| داده‌ی قیمتی | پروکسی Yahoo Finance (نمادهای GC=F, SI=F, EURUSD=X, BTC-USD) |
| تحلیل | موتور محلی market-structure (بدون سرویس خارجی) |

## 🚀 اجرای پروژه

```bash
# نصب وابستگی‌ها
npm install

# ساخت دیتابیس
npx prisma generate
npx prisma db push

# اجرای محیط توسعه
npm run dev

# ساخت نسخه‌ی پروداکشن
npm run build && npm start
```

پروژه روی `http://localhost:3000` اجرا می‌شود.

## 📁 ساختار پروژه

```
├── src/
│   ├── app/                  # صفحات و API Routes (پروکسی داده، تحلیل، اخبار)
│   ├── components/phone/     # رابط موبایلی: پوسته‌ی گوشی + اپ‌های داخلی
│   └── lib/                  # موتور تحلیل ساختار بازار (market-structure)
├── scripts/
│   ├── build-standalone.mjs  # ساخت نسخه‌ی مستقل HTML
│   └── standalone/           # سورس نسخه‌ی مستقل (app.c.js + head.html)
├── download/
│   ├── rasadgar-dollar.html  # ✅ نسخه‌ی مستقل نهایی
│   └── rasadgar-dollar-wp.zip# ✅ افزونه‌ی وردپرس
├── upload/                   # اندیکاتور Pine Script (SBW·OB·4H·Div) و لوگو
├── prisma/schema.prisma      # اسکیمای دیتابیس
└── public/                   # لوگو و فایل‌های استاتیک
```

## 📱 نسخه‌ی مستقل HTML

فایل `download/rasadgar-dollar.html` کاملاً خودکفاست: تمام استایل‌ها، اسکریپت‌ها و منطق داخل یک فایل تزریق شده‌اند. کافی است فایل را به موبایل خود بفرستید (ایمیل / تلگرام) و در مرورگر باز کنید. برای بازسازی این فایل پس از هر تغییر در سورس:

```bash
node scripts/build-standalone.mjs
```

## ⚠️ نکات مهم

- داده‌ی قیمتی از Yahoo Finance گرفته می‌شود؛ برای نماد طلا از قرارداد آتی `GC=F` استفاده می‌شود که ممکن است با قیمت اسپات کارگزار (مانند OANDA) اختلاف جزئی (Base) داشته باشد.
- این ابزار فقط تحلیل و پیشنهاد نمایش می‌دهد؛ **هیچ سفارشی به‌صورت خودکار ثبت نمی‌کند**.
- ریسک معاملاتی با خود کاربر است؛ خروجی‌های ابزار توصیه‌ی مالی نیستند.
